# 🚀 CodeAlpha Machine Learning Internship Projects

## 📌 Overview

This repository contains the Machine Learning and Deep Learning projects completed during my **CodeAlpha Machine Learning Internship**. These projects demonstrate skills in data preprocessing, exploratory data analysis (EDA), machine learning, deep learning, model evaluation, and prediction using real-world datasets.

---

## 📂 Projects

### 🔹 Task 1: Credit Scoring Model

**Objective**

Predict whether a customer is a good or bad credit risk using historical financial data.

**Dataset**

- German Credit Dataset

**Algorithms**

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

**Best Model**

- Random Forest Classifier

**Skills Used**

- Data Preprocessing
- Feature Engineering
- Label Encoding
- Feature Scaling
- Model Evaluation

---

### 🔹 Task 3: Handwritten Character Recognition

**Objective**

Recognize handwritten digits using a Convolutional Neural Network (CNN).

**Dataset**

- MNIST Dataset

**Model**

- Convolutional Neural Network (CNN)

**Accuracy**

- **98.75%**

**Skills Used**

- Deep Learning
- Image Processing
- CNN
- TensorFlow / Keras

---

### 🔹 Task 4: Heart Disease Prediction

**Objective**

Predict the possibility of heart disease using patient medical data.

**Dataset**

- Heart Disease Dataset

**Algorithms**

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)

**Best Model**

- Random Forest Classifier (**98.54% Accuracy**)

**Skills Used**

- Data Analysis
- Classification
- Model Comparison
- Medical Data Prediction
